# Custom Act II backgrounds

Upload your own images into this folder using these exact filenames:

- baby.png
- gymnastics.png
- usa.png
- coach.png
- meet-breakup.png
- paris.png
- birthday-reunion.png
- paris-romance.png
- milan.png
- como.png
- etretat.png
- mallorca.png

Recommended:
- JPG
- landscape orientation
- ideally 16:9
- at least 1600×900
- keep each image reasonably compressed for fast loading

The game is already wired to these filenames.
After uploading/replacing the photos, just commit and push to main.
GitHub Actions will rebuild and deploy automatically.
